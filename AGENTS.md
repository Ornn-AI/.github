# Repository Instructions

- Keep the public profile professional, concise, and suitable for external
  partners, customers, and investors.
- Do not mention private or internal repositories in the public profile unless
  the repository has intentionally been made public.
- When a Linear ticket is associated with a change, update that ticket with the
  change summary and documentation status before finishing.
- Before opening a PR, update the branch with the latest `main` unless the PR is
  only an automatic merge.
- Keep documentation current with each change, including this file when workflow
  expectations change.
